# Blinkit Sales Data Analysis Using SQL and Power BI

## 1. Project Overview

This project focuses on analyzing Blinkit sales data using SQL and Microsoft Power BI. The main objective is to understand sales performance, product categories, outlet performance, customer ratings, and business trends through data analysis and visualization.

The project helps identify useful business insights that can support better decision-making.

## 2. Project Objectives

- Analyze total sales performance.
- Identify top-performing product categories.
- Compare sales across different outlet types.
- Analyze sales by outlet location tier.
- Understand customer ratings.
- Create an interactive Power BI dashboard.
- Generate meaningful business insights using SQL.

## 3. Tools and Technologies

- SQL
- Microsoft Power BI
- DAX
- CSV Dataset
- Data Visualization

## 4. Dataset Description

The dataset contains sales-related information such as:

- Item Identifier
- Item Type
- Item Fat Content
- Item Sales
- Outlet Identifier
- Outlet Type
- Outlet Location Tier
- Outlet Establishment Year
- Customer Rating

Note: The repository includes a sample dataset and supporting project files.

## 5. SQL Analysis

SQL is used to create the database, store the data, and perform analytical queries.

The analysis includes:

- Sales by Item Type
- Sales by Outlet Type
- Sales by Location Tier
- Sales by Fat Content
- Average Customer Rating

## 6. Power BI Dashboard

The Power BI dashboard is designed to present sales performance visually.

Dashboard components include:

- Total Sales KPI
- Average Sales
- Number of Items
- Average Customer Rating
- Sales by Item Type
- Sales by Outlet Type
- Sales by Location Tier
- Interactive Filters and Slicers

## 7. Key Insights

The project aims to identify:

- Product categories contributing to sales.
- Outlet types with better sales performance.
- Differences in sales across location tiers.
- Customer rating patterns.
- Opportunities for business improvement.

## 8. Project Files

- SQL: Database creation and analysis queries.
- Dataset: Sample sales data.
- Power BI: Dashboard-related files and guide.
- Dashboard Preview: Visual chart images.
- Documentation: Project report and instructions.

## 9. Conclusion

This project demonstrates how SQL and Power BI can be used together for business data analysis. SQL helps organize and analyze the data, while Power BI transforms the results into meaningful visualizations.

The project provides a basic understanding of sales analytics and business intelligence.
